# 2026-03-23 `cc-connect sessions` 会话发现命令说明

## 1. 背景

当前 `cc-connect` 已在内部 API 提供 `/sessions`，但 CLI 缺少可直接供 UI/脚本调用的命令入口。  
为支撑前端“发现活跃会话（project/session_key/platform）”能力，需要补齐 `cc-connect sessions --json`。

## 2. 变更摘要

### 2.1 新增 CLI 命令 `cc-connect sessions`

- 新文件：`cmd/cc-connect/sessions.go`
- 子命令支持：
  - `--json`：输出会话数组 JSON
  - `-p, --project`：按项目过滤
  - `--data-dir`：覆盖默认数据目录
- 返回结构字段：
  - `project`
  - `session_key`
  - `platform`

### 2.2 主入口挂载

- 修改：`cmd/cc-connect/main.go`
- 新增 `sessions` 子命令路由到 `runSessions`。

### 2.3 `/sessions` API 增强

- 修改：`core/api.go`
- `/sessions` 增加可选查询参数 `project`：
  - 未传：返回所有项目的活跃会话
  - 传入存在项目：返回该项目会话
  - 传入不存在项目：返回 `404` + 明确错误 `project "<name>" not found`

## 3. 异常行为与退出码

`cc-connect sessions` 在以下情况返回非 0 退出码并输出明确错误：

1. socket 缺失：`cc-connect is not running (socket not found: ...)`
2. cc-connect 未启动（连接失败）：`failed to connect to cc-connect: ...`
3. project 不存在（服务端 404）：`project "<name>" not found`

## 5. 影响/风险与回滚

### 影响面

1. CLI 新增 `sessions` 子命令；
2. `/sessions` 新增 `project` 过滤与 404 行为。

### 风险

- 风险较低：属于增量能力，默认行为保持（不传 project 仍可拉取全量会话）。

### 回滚建议

若需回滚，按以下文件一次性回退：

1. `cmd/cc-connect/sessions.go`
2. `cmd/cc-connect/main.go`
3. `core/api.go`
4. `cmd/cc-connect/sessions_test.go`
5. 本说明文档

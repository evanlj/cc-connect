# 2026-03-22 飞书发送本地文件命令实现说明

## 1. 背景

在多 Bot 协作与需求落地流程中，主持人或执行者会生成较长的 Markdown 结果文档（方案、结论、复盘等）。  
此前 cc-connect 仅支持 `send` 文本消息，无法直接把本地文档作为文件附件发送到飞书会话，导致：

- 长文档需要手工复制粘贴，易截断；
- 群内归档不方便；
- 自动化流程中“产出文档 → 回传到会话”无法闭环。

## 2. 变更概览

本次新增 **`send-file` 能力**，支持通过本地 API + CLI 将文件上传并发送到飞书会话。

### 2.1 核心能力

1. `core` 增加可选接口：`FileSender`
2. `Engine` 增加：`SendFileBySessionKey(sessionKey, filePath)`
3. API 新增端点：`POST /send-file`
4. CLI 新增命令：`cc-connect send-file`
5. 飞书平台新增文件发送实现（上传文件 + 发送 file 消息）

### 2.2 涉及文件

- `core/interfaces.go`
- `core/engine_ask.go`
- `core/api.go`
- `core/engine_ask_test.go`
- `cmd/cc-connect/main.go`
- `cmd/cc-connect/send_file.go`
- `platform/feishu/feishu.go`
- `platform/feishu/feishu_file_test.go`

## 3. 使用说明

### 3.1 CLI

```bash
cc-connect send-file -s "feishu:oc_xxx:ou_yyy" "D:\docs\讨论结论.md"
```

可选参数：

- `-p, --project`：项目名（多项目时建议显式指定）
- `-s, --session`：会话 key（也支持 `CC_SESSION_KEY` 环境变量）
- `--file`：文件路径（也可直接用位置参数）
- `--data-dir`：实例数据目录

### 3.2 API

请求：

```json
POST /send-file
{
  "project": "xxx",
  "session_key": "feishu:oc_xxx:ou_yyy",
  "file_path": "D:\\docs\\讨论结论.md"
}
```

成功响应：

```json
{"status":"ok"}
```

## 4. 行为与约束

- 仅当目标平台实现了 `ReplyContextReconstructor + FileSender` 时可用；
- 当前重点支持飞书平台；
- 会校验文件存在且不是目录；
- 飞书上传使用文件后缀映射类型（`pdf/doc/xls/ppt/mp4/opus`，其余默认 `stream`）；
- Markdown 文件（`.md`）按 `stream` 上传。

## 5. 验证证据

本地验证建议执行：

```bash
go test ./core
go test ./platform/feishu
go build -o cc-connect.exe ./cmd/cc-connect
```

并在真实会话执行：

```bash
cc-connect send-file -s "feishu:oc_xxx:ou_yyy" "D:\docs\讨论结论.md"
```

预期：飞书会话中出现文件消息，文件名与本地一致。

## 6. 影响与风险

### 正向影响

- 文档回传自动化能力增强；
- 降低超长文本在 IM 中的截断与格式损失风险；
- 便于群内沉淀“最终产出物”。

### 风险点

- 平台侧权限不足会导致上传失败；
- 文件大小受飞书接口限制（官方限制下的上传失败需提示用户）；
- 文件路径不合法会直接返回错误。

## 7. 回滚方案

回滚后不影响原有 `send`/`ask` 文本能力。

# 2026-03-24 飞书Squad卡片文本触发恢复说明

## 背景

用户反馈：在飞书中发送 `菜单` 可以弹出菜单卡片，但发送 Squad 触发词（如 `/squad-card`、`squad控制卡`）不再弹出 Squad 审核控制卡。

排查发现，文本消息入口仅保留了“菜单卡片”触发分支，缺少 Squad 卡片文本触发分支，导致相关文本会直接进入普通对话流程，而不会走卡片发送逻辑。

## 变更摘要

文件：`platform/feishu/feishu.go`

1. 在文本消息处理分支补回 Squad 卡片触发：
   - 当命中 Squad 文本触发词时，直接打开 Squad 控制卡并返回。

2. 新增 `shouldShowSquadControlCard(text string) bool`：
   - 支持触发词：
     - `/squad-card`
     - `/squad_card`
     - `squad卡片`
     - `squad 控制卡`
     - `squad控制卡`
     - `squad 审核控制卡`
   - 与菜单触发一致，先做 `@提及` 清理和基础文本归一化，避免群聊格式影响命中。

3. 新增 `openSquadControlCardForSession(...)`：
   - 优先按 `message_id` 回复卡片；
   - 失败时回退按 `chat_id` 新发卡片；
   - 自动带入当前会话最新 `run_id`（若存在）。

## 影响与风险

### 正向影响

- 恢复文本触发 Squad 卡片能力，和“菜单触发”并行可用。
- 群聊/私聊场景下的稳定性更好（reply 失败可回退 send）。

### 风险

- 若飞书侧缺失卡片发送权限，仍可能出现“打开失败”日志；但不影响普通消息通道。

## 验证证据

建议执行：

1. 单测（触发词匹配）  
   `go test ./platform/feishu -run TestShouldShowSquadControlCard -count=1`

2. 全量平台测试  
   `go test ./platform/feishu`

3. 端到端验证  
   在飞书群发送：
   - `/squad-card`
   - `squad控制卡`
   
   预期：可直接弹出 Squad 审核控制卡；发送 `菜单` 仍可弹出菜单卡片。

## 回滚说明

如需回滚，可移除：

- 文本消息分支中的 Squad 卡片触发判断；
- `shouldShowSquadControlCard` 与 `openSquadControlCardForSession` 两个函数。

回滚后执行 `go test ./platform/feishu` 验证。
